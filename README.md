# 失業手当受給額計算ツール

雇用保険の基本手当（失業手当）の受給額を計算するWebアプリケーションです。2024年8月時点の雇用保険法に基づいて計算します。

## 機能

- **受給額計算**: 賃金日額・年齢・被保険者期間・離職理由から基本手当日額・給付日数・総受給額を算出
- **AI解説**:
  - 「簡単に解説」: Claude Haiku による簡潔な説明
  - 「詳しく解説」: Claude Sonnet による詳細な説明
- **URL共有**: 計算結果をURLパラメータとして共有可能
- **レスポンシブデザイン**: スマートフォン・タブレット・PCに対応

## 技術スタック

- **フレームワーク**: Next.js 15 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **AI**: Anthropic Claude API (Haiku / Sonnet)
- **デプロイ**: Vercel

## セットアップ

### 前提条件

- Node.js 18.17 以上
- Anthropic API キー（[Anthropic Console](https://console.anthropic.com/) で取得）

### ローカル開発手順

1. リポジトリをクローン

```bash
git clone <repository-url>
cd sitsugyouhoken-keisan
```

2. 依存パッケージをインストール

```bash
npm install
```

3. 環境変数を設定

`.env.example` をコピーして `.env.local` を作成し、APIキーを設定します：

```bash
cp .env.example .env.local
```

`.env.local` を編集して、実際の API キーを設定してください：

```
ANTHROPIC_API_KEY=your_anthropic_api_key_here
```

4. 開発サーバーを起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) にアクセスしてください。

## Vercel へのデプロイ

### 方法1: Vercel CLI

```bash
npm install -g vercel
vercel
```

### 方法2: Vercel ダッシュボード

1. [Vercel](https://vercel.com) にログイン
2. 「New Project」をクリック
3. このリポジトリをインポート
4. **Application Preset**: `Next.js` を選択
5. **環境変数の設定**（重要）:
   - Name: `ANTHROPIC_API_KEY`
   - Value: あなたの Anthropic API キー
6. 「Deploy」をクリック

### 環境変数の設定

Vercel のプロジェクト設定 → **Settings** → **Environment Variables** で以下を設定：

| Name | Value | 環境 |
|------|-------|------|
| `ANTHROPIC_API_KEY` | `sk-ant-...` | Production, Preview, Development |

> **セキュリティ**: APIキーは絶対にソースコードにハードコードせず、環境変数として管理してください。

## 計算ロジック

### 給付率の計算（2024年8月時点）

| 賃金日額 | 給付率 |
|---------|--------|
| 5,110円以下 | 80% |
| 5,110円超〜12,580円以下 | 80%〜50%（線形補間） |
| 12,580円超 | 50% |

### 基本手当日額の上限

| 年齢区分 | 上限額 |
|---------|--------|
| 30歳未満 | 6,945円 |
| 30〜44歳 | 7,715円 |
| 45〜59歳 | 8,490円 |
| 60〜64歳 | 7,294円 |

### 給付日数（自己都合）

| 被保険者期間 | 給付日数 |
|-------------|---------|
| 1〜9年 | 90日 |
| 10〜19年 | 120日 |
| 20年以上 | 150日 |

### 給付日数（会社都合）

| 被保険者期間 | 30歳未満 | 30〜44歳 | 45〜59歳 | 60〜64歳 |
|-------------|---------|---------|---------|---------|
| 1年未満 | 90日 | 90日 | 90日 | 90日 |
| 1〜4年 | 90日 | 120日 | 180日 | 150日 |
| 5〜9年 | 120日 | 180日 | 240日 | 180日 |
| 10〜19年 | 180日 | 240日 | 270日 | 210日 |
| 20年以上 | 180日 | 270日 | 330日 | 240日 |

## URL共有パラメータ

計算結果は以下のURLパラメータとして共有できます：

| パラメータ | 説明 | 例 |
|-----------|------|-----|
| `dw` | 賃金日額 | `10000` |
| `ag` | 年齢区分 | `30to44` |
| `ip` | 被保険者期間（年） | `5` |
| `rt` | 離職理由 | `voluntary` または `company` |

例: `https://your-app.vercel.app/?dw=10000&ag=30to44&ip=5&rt=voluntary`
